# Capacitación en CSPro
El **Census and Survey Processing System (CSpro)** es un software utilizado para el procesamiento de encuestas. Permite la generación de plantillas de digitación de encuestas complejas, validación y tabulación de datos censales y encuestas, y la exportación automatizada de múltiples bases de datos a programas como SPSS, STATA, R, entre otros. Este repositorio incluye materiales de capacitación de CSPro.

## 📋 A quién va dirigido

Este material está pensado para Curso pensado para estudiantes, profesionales e investigadores de ciencias sociales y disciplinas afines interesados en ampliar sus conocimientos en el procesamiento de data cuantitativa, tanto en el diseño e implementación de captura de datos para encuestas y/o censos.

## 🚀 Cómo usar este repositorio

1. Clona el repositorio:
   ```bash
   git clone https://github.com/adrianaraygada/CSPro.git
   ```
2. Instala CSPro siguiendo la guía en `00-introduccion/instalacion-configuracion.md`.
3. Sigue las sesiones en orden: revisa las slides correspondientes en `01-slides/`, luego resuelve los ejercicios en `02-ejercicios/`.
4. Usa `03-proyectos-ejemplo/` como referencia cuando construyas tu propia aplicación.

## 🤝 Contribuciones

Si utilizas este material para dictar o aprender sobre CSPro y encuentras un error o quieres aportar un ejercicio adicional, siéntete libre de abrir un *issue* o un *pull request*. 

1. Haz un Fork del repositorio a tu cuenta de GitHub.
2. Clona tu fork localmente
3. Crea una nueva rama para tus cambios: git checkout -b mi-mejora-o-correccion
4. Realiza los cambios que consideres necesarios y haz commit de tus modificaciones.
5. Sube la rama a tu repositorio forkeado: git push origin mi-mejora-o-correccion
6. Finalmente, abre un Pull Request desde tu repositorio de GitHub hacia este repositorio principal.

Revisaré tu contribución a la brevedad posible. ¡Gracias por tu colaboración!
